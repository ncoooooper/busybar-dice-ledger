# Dice Ledger

Roll a tabletop dice pool, retain successes, and reroll only the dice that missed.

Turn the wheel before rolling to choose 1–8 dice. Start cycles success threshold 2–6. Click rolls the initial pool and then only the failures. The front displays individual faces; successes are highlighted. Hold Start clears the pool for the next player.

## Run locally

From this folder, run `~/.busy-emulator/bin/busy-emulator dev --once` with BUSY Bar Emulator open. Back exits.
